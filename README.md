# 2. Full-atomic structure generation and RNA refinement
This package offers two methods for structure refinement and the prediction of base-pairing and base-stacking interactions: an automated process and a customizable process.  
The automated process enables structure refinement without detailed parameter settings,  
while the customizable process allows for user-defined adjustments to each process.  

## 2-1. Automated process
The RNAref3D predicts base-pair and base-stacking interactions using geometric attention-based neural network models. 
Next, an full-atomic structure is generated by superimposing structural fragments—specifically base-pair and single nucleotide fragments—onto the input backbone structure. 
Finally, the generated full-atomic structure is refined by Monte-Carlo (MC) simulation and L-BFGS based energy minimization, which are guided by the predicted base-pair and base-stacking information.  

  
### 2-1. Base-pairing and base-stacking prediction
RNAref3D predicts base-pair and base-stacking interactions by geometric attention-based neural network models.
```
python RNAref3D/RNAref3Dbp/main.py --pdb <input_pdb_file> -o <output_directory> [other options]
```
(Options)
| Option  | Description | Default |
| :-------------: | :-------------: | :-------------: |
| --pdb  | Path to the PDB file containing the backbone structure | Required |
| -o  | Output directory | Required |
| -bp  | To predict base-stacking interactions only from base-pair information, specify the path to the base-pair file | None |   

(Refer to the /RNAref3D/example/RNAref3D_bp.txt for the format of the base-pair file)

<br>

example)   
If you want to obtain the base-pair and base-stacking interactions, run the following command.  
```
python RNArefiner/bin/bppredictor.py --pdb ./input.pdb  -o ./output
```
  
If you only want to predict base-stacking interactions from base-pair information, run the following command.  
```
python RNArefiner/bin/bppredictor.py --pdb ./input.pdb  -o ./output -bp ./RNAref3D_bp.txt
```
As a result, the files RNAref3D_bp.txt and RNAref3D_stack.txt are output to the directory specified by -o.

### 2-2. Full-atomic structure generation and RNA 3D structure refinement
The following command executes the full-atomic structure generation and refinements of RNA 3D structures.
```
/RNAref3D/bin/RNAref3D -i <input_pdb_file> -o <output_directory> -bp <input_bp_file> -st <input_st_file> [other options]
```
Here, base-paring and base-stacking interaction information must be inputted as follows.  
(Options)  
| Option | Description | Default |
| :-------------: | :-------------: | :-------------: |
| -i | Path to the PDB file containing the backbone structure | Required |
| -o | Output directory | Required |
| -bp | Path to the base-pair file | Required |
| -st | Path to the base-stacking file | Required |
| -m | Refinement types (0-3) | 3 |
| -mtime | MC-based refinement time [seconds] | 7200 |
| -ltime | L-BFGS-based refinement time [seconds] | 3600 |
| -verbose | Enables detailed logging. Log is written to output/directory/logs/output.log. | False |
| -libdir | Directory of user-defined template structures (All PDB files in the directory are loaded, NOW NOT AVAILABLE) | None |
  
The refinement type can be selected from the following options.
| Mode | Description |
| :-------------: | :-------------: |
| 1 | Full atomic structure generation only |
| 2 | MC-based refinement |
| 3 | L-BFGS-based refinement |
| 4 | MC-based refinement + L-BFGS-based refinement |
